# 1. 它是怎么工作的

看完这页，你应该能明白：为什么只给一个名字就能显示图标。

参考资料，不是任务清单。资料核实日期：2026-09-18。

## 1.1 一句话概括

**图标名决定画什么，size 和 color 决定怎么画，下载和缓存由库自己管。**

## 1.2 图标名是什么

```text
mdi : home
└┬┘   └┬─┘
 │     └── 图标名
 └──────── 图标集合（Material Design Icons）
```

Iconify 收录了 200 多个图标集合。集合名加图标名，就能唯一确定一个图标。

自定义来源写成 `@内部来源:集合:名字`，例如 `@company:app:logo`。

## 1.3 下载的是 JSON，不是 SVG 文件

很多人以为 Iconify 是下载 `.svg` 文件，其实主要是请求 JSON：

```text
https://api.iconify.design/mdi.json?icons=account,home
```

返回内容大致如下（简化）：

```json
{
    "prefix": "mdi",
    "width": 24,
    "height": 24,
    "icons": {
        "home": {
            "body": "<path d=\"M10 20v-6h4v6h5v-8h3L12 3L2 12h3v8h5z\" fill=\"currentColor\"/>"
        }
    }
}
```

关键点：

- `body` 是 SVG 的**内部内容**，不是完整 SVG 文件。
- 宽高可以写在集合层级，省略时表示所有图标共用。
- 客户端拿到数据后，自己拼出完整 SVG 再显示。

所以我们的库也只需要处理 JSON，不需要 Node.js。

**术语**：`currentColor` 是 SVG 的写法，意思是「用当前文字颜色」。这也是单色图标能换色的原因。多色图标（如 Google 图标、国旗）把色值写死，没有这个占位，所以换不了色——官方也是如此。

## 1.4 官方图标数据从哪来

| 来源                     | 用途                            |
| ------------------------ | ------------------------------- |
| 官方 API                 | 运行时按需获取，需要联网        |
| `iconify/icon-sets` 仓库 | 全部集合的 JSON，适合构建时取用 |
| 你自己写的 JSON          | 私有图标，完全离线              |

我们的库不自带全部图标，那会有几百 MB。

## 1.5 显示一个图标的完整过程

```text
图标名
  ↓
查内存里有没有这个图标的数据
  ├── 有 → 直接生成 SVG 显示
  └── 没有 → 后台请求 JSON → 存进内存 → 通知界面刷新
```

要点：

- 多个控件用同一个图标，只请求一次。
- 同一时刻要多个图标，可以合并成一次请求。
- 数据只存一份；显示成不同大小、不同颜色都复用它。

## 1.6 分成哪几层

| 层     | 负责什么                                     | 需要 Qt 吗 |
| ------ | -------------------------------------------- | ---------- |
| 数据层 | 解析名字、解析 JSON、注册图标、生成 SVG 文本 | 不需要     |
| 加载层 | 请求数据、合并请求、缓存、通知刷新           | 需要       |
| 显示层 | 用 Qt 画出来、处理颜色和尺寸                 | 需要       |
| 控件层 | `IconWidget`、按钮图标                       | 需要       |

**数据层不依赖 Qt**，这样能单独测试，也方便以后写命令行打包工具。

## 1.7 几个要提前知道的坑

### Qt 画 SVG 的能力比浏览器弱

Qt 支持的是 SVG 的一个子集，部分滤镜、遮罩、CSS 动画不支持。

**对策**：只承诺常用静态图标可用；遇到不支持的内容，明确报错，不假装画对了。

### 颜色不会自动继承

浏览器里 `currentColor` 由 CSS 自动处理，Qt 没有这套机制。

**对策**：由我们读取控件的文字颜色，替换到 SVG 里。多色图标保持原样，不强行染色。

这也是亮暗主题自动适配的实现方式：图标跟随文字色，主题一变，文字色变，图标跟着变。需要监听调色板变化事件，并让已生成的位图失效。

### 高分屏要按真实像素画

在 150% 缩放的屏幕上，24 逻辑像素的图标实际要画 36 个物理像素，否则会模糊。

**对策**：Qt 的 `QIconEngine.scaledPixmap` 会传入屏幕缩放比（`scale` 参数，尺寸本身是逻辑像素），我们据此渲染对应分辨率的图，并标记缩放比。

缓存要按「缩放比 + 颜色 + 尺寸 + 角度」区分，否则跨屏拖动或换主题后会拿到旧图。

### 下载不能卡界面

如果在绘制时等网络，界面会卡住。

**对策**：绘制时只用已有数据；下载在后台进行，完成后再刷新。

## 1.8 不做的事

- 不做图标搜索界面（可以以后做成独立工具）
- 不支持 SVG 自带动画
- 不引入浏览器内核
- 不自动修改你程序的全局 Qt 设置
