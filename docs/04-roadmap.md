# 4. 开发计划

分四步走。每步都有明确的完成标准。

## 4.1 总览

| 阶段   | 做什么                   | 状态                                                                     |
| ------ | ------------------------ | ------------------------------------------------------------------------ |
| Step 0 | 定方案、搭目录           | 已完成                                                                   |
| Step 1 | 离线显示图标             | 实现完成，离屏诊断全部通过；系统主题 / 多屏高分屏 / 大列表性能待真机验收 |
| Step 2 | 联网下载和缓存           | 实现完成，离屏测试与真网络冒烟通过                                       |

Step 1 的功能已实现，可运行 `examples/step1_demo.py` 查看。

## 4.3 Step 1：离线显示图标

### Step 1 做什么

1. 解析图标名（`mdi:home` → 集合 + 名字）
2. 解析 Iconify 的 JSON，处理默认宽高和别名
3. 提供 `add_icon` / `add_collection` 注册本地图标
4. 颜色解析：颜色名、HEX 3 / 4 / 6 / 8 位、`rgb()`、`rgba()`、`hsl()`、`hsla()`、元组、`QColor`，另加 `hex_argb()` / `hex_rgba()`
5. 颜色三参数 `color` / `light_color` / `dark_color`，以及 `{原色: 新色}` 映射表换色
6. 从图标数据生成完整 SVG，处理 `currentColor`
7. 用 Qt 画出来，按屏幕缩放比渲染物理像素
8. 实现 `IconWidget` 和 `get_icon`，支持 `size`、`color`、`rotate`、`opacity`
9. `size` 多种写法：数字、元组、`QSize`、`"24px"`、`"1.5em"`
10. 亮暗主题自动跟随、禁用状态按透明度变淡
11. `spin` 旋转动画，共享定时器、不可见时暂停
12. 状态区分：加载中空白、不存在显示占位图，支持 `fallback`
13. `set_default_config()` 全局默认值
14. 三层缓存与缓存键，容量上限
15. QSS 支持：`color`、`background`、`qss` 分组属性与 Qt 原生 `setStyleSheet()`
16. 类型标注全覆盖 + `py.typed`
17. 主线程检查与 `WrongThreadError`，数据层加锁
18. `logging` 接入，默认静默
19. `is_monotone()`、`get_icon_colors()`、`set_disabled_opacity()`、`set_cache_limits()`

### Step 1 完成标准

- 断网、无缓存，也能显示注册进去的图标
- `size` 和 `color` 生效
- `size` 的每种写法都正确：数字、元组、`QSize`、`"24px"`、`"1.5em"`
- `"1em"` 等于控件当前字号，字号变化后自动跟着变
- 列出的每种颜色写法都能正确解析，带透明度的 HEX 默认按 `#RRGGBBAA`
- `hex_argb("#80ff0000")` 与 `hex_rgba("#ff000080")` 得到同一个颜色
- 非法颜色报 `InvalidColorError`，不静默变黑
- `rotate` 支持任意角度，斜放时图形不被裁掉
- 多色图标传单个颜色时保持原配色，不被染成单色
- 多色图标传映射表时只替换列出的颜色，其余不动
- 映射表的键按解析后的颜色匹配，`#4285F4` 与 `rgb(66,133,244)` 等价
- `light_color` / `dark_color` 优先于 `color`，只写一个时另一主题回退到自动跟随
- 不填颜色时跟随主题：亮色主题深色图标、暗色主题浅色图标
- 运行中切换主题（系统主题 / QSS / `setPalette`）图标自动更新
- 按钮禁用时图标按透明度变淡，多色图标配色不变
- 透明度相乘正确：`opacity=0.5` 的图标在禁用按钮上最终为 `0.5 × 0.4 = 0.2`
- 颜色自带 alpha、`opacity`、禁用系数三者叠加时结果正确且不超出 0—1
- `spin=True` 能转；控件隐藏或窗口最小化时定时器暂停
- 多个 `spin` 图标共用一个定时器，不是每个开一个
- **加载中显示空白，不显示占位图**
- **确认不存在时显示占位图并发 `failed` 信号**
- `fallback` 指定的替代图标生效；替代图标也失败时退回内置占位图，不递归
- 内置占位图在没有任何图标数据时也能画出来
- `set_default_config()` 生效，参数写法优先于默认值
- 改默认值不影响已创建的图标
- 100% / 125% / 150% / 200% 缩放下都清晰，视觉大小一致
- 窗口拖到不同缩放比的屏幕后重新渲染
- 缓存键覆盖所有影响画面的参数，改任一参数都能正确重画
- QSS 的 `color` 能改图标颜色，`background` 能画出背景
- Qt 动态属性配合属性选择器生效，运行中修改并刷新样式后立即更新
- 显式颜色参数不被 QSS 覆盖
- 非主线程调用 Qt 接口报 `WrongThreadError`，后台线程注册数据正常
- 类型检查通过，`py.typed` 随包分发
- 默认不产生任何日志输出，开 DEBUG 后能看到缓存命中情况
- 图标数据坏了会明确报错，不是显示空白
- 数据层在没有 Qt 的环境也能导入
- 基准测试脚本可运行，产出可对比的数字（详见[性能文档](05-performance.md)）

## 4.4 Step 2：联网下载和缓存

### Step 2 做什么

1. 实现下载，用 Qt 自带的网络模块（不额外引入依赖）
2. 多个控件请求同一图标时合并成一次请求
3. 内存缓存 + 磁盘缓存
4. 支持严格离线模式
5. 处理控件销毁、取消请求、迟到的响应
6. 下载完成后自动刷新控件

### Step 2 完成标准

- 加载过程中界面不卡
- 同一图标只请求一次
- 「网络失败」和「图标不存在」能区分开
- 反复切换图标不会出现旧图覆盖新图
- 离线模式下不发出任何请求

实现说明（2026-09-21）：下载用 QtNetwork，50ms 凑批按前缀合并请求；磁盘缓存存原始 JSON（Qt 标准缓存目录，7 天过期）；失败有记忆、`reset_failures()` 后才重试。运行 `examples/step2_demo.py` 可查看联网效果。

## 4.8 已确认的决定

| 决定        | 结论                                                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 优先支持    | PySide6                                                                                                                                     |
| Python 下界 | 3.10                                                                                                                                        |
| 许可证      | MIT                                                                                                                                         |
| 尺寸参数    | `size`，默认 24；可传数字、元组、`QSize`、`"24px"`、`"1.5em"`                                                                               |
| 颜色参数    | 颜色名 / HEX 3·4·6·8 位 / rgb() / rgba() / hsl() / hsla() / 元组 / QColor；带透明度的 HEX 默认 `#RRGGBBAA`，Qt 顺序用 `hex_argb()` 显式声明 |
| 主题适配    | 不填颜色时自动跟随亮暗主题与禁用状态；`light_color` / `dark_color` 可分别指定，优先于 `color`                                               |
| 多色换色    | 颜色参数可传 `{原色: 新色}` 映射表；多色图标传单个颜色不生效，保持原配色                                                                    |
| 禁用状态    | 用透明度变淡（默认 0.4），不换成灰色；`set_disabled_opacity()` 可调                                                                         |
| 透明度叠加  | 颜色 alpha × `opacity` × 状态系数，相乘而不是覆盖                                                                                           |
| 动画        | `spin=True`，共享定时器，控件不可见时暂停                                                                                                   |
| 高分屏      | `size` 是逻辑像素，按屏幕缩放比渲染物理像素，不需要多套图                                                                                   |
| 加载 / 缺失 | 加载中显示空白，确认不存在才显示占位图并报错；`fallback` 可指定替代图标                                                                     |
| 全局默认    | `set_default_config()` 统一设置，参数写法优先于默认值                                                                                       |
| QSS         | 支持 `color`、`background`；构造时用 `qss` 分组，样式用原生 `setStyleSheet()`；优先级 参数 → QSS → 主题                                     |
| 类型提示    | 全覆盖 + `py.typed`，CI 跑类型检查                                                                                                          |
| 线程        | Qt 接口限主线程，违者报 `WrongThreadError`；数据层加锁允许后台线程                                                                          |
| 日志        | 标准 `logging`，logger 名 `pyside_iconify`，默认静默                                                                                        |
| 性能        | 硬指标，单独见 05-performance.md；三层缓存 + 容量上限 + 基准测试进 CI                                                                       |
| 悬停 / 选中 | Step 3 再做                                                                                                                                 |
| 旋转参数    | 只有 `rotate`，接受任意角度，自动缩小避免裁剪                                                                                               |
| 目录布局    | 保留 `src/`                                                                                                                                 |
| 阶段命名    | Step 0—4                                                                                                                                    |
| PySide2     | 暂不支持，后续评估                                                                                                                          |
| PyQt        | 暂不支持，将来优先考虑 PyQt6                                                                                                                |

## 4.9 为什么用 src 布局

`src/pyside_iconify/` 与 `pyside_iconify/` 两种写法都合法。外层是仓库名，内层才是 Python 包名。

选 `src` 的原因：**避免在仓库里直接运行时误导入未安装的源码**，从而掩盖打包配置的问题。用户安装后写 `import pyside_iconify`，看不到 `src` 这一层。

代价是开发时要先做一次可编辑安装（`uv sync` 会处理）。不喜欢也可以改成扁平布局，只需同步打包配置。

参考：<https://packaging.python.org/en/latest/discussions/src-layout-vs-flat-layout/>
