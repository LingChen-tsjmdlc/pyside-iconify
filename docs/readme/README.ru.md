# pyside-iconify

**Дайте `QIcon` источник данных.**

[English](../../README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | **Русский** | [Português (BR)](README.pt-BR.md)

```python
IconWidget("mdi:home", color="red")
```

Одна строка — один значок. Никаких файлов SVG или PNG в управлении — значки
получаются по требованию по имени из экосистемы
[Iconify](https://iconify.design) и автоматически кэшируются. Результат —
всегда стандартный `QIcon`, работает с любым виджетом, принимающим значки.

> **Статус**: активная разработка, ещё не опубликовано на PyPI. Публичный API
> может измениться до первого релиза.
>
> Этот проект **не** связан с официальным проектом Iconify.

## Зачем

| Без                                             | С pyside-iconify                      |
| ----------------------------------------------- | ------------------------------------- |
| `QIcon("assets/home.svg")`                      | `get_icon("mdi:home")`                |
| Управление файлами SVG/PNG и путями             | Значки по имени из экосистемы         |
| Наборы ресурсов для цветов и размеров           | `color`, `size`, `rotate` — параметры |
| Разводка значков по виджетам вручную            | Стандартный `QIcon`, работает везде   |
| Ручные варианты значков для светлой/тёмной темы | Автоматически следует палитре виджета |

## Быстрый старт

```powershell
pip install "pyside-iconify[pyside6]"
```

```python
from PySide6.QtWidgets import QApplication, QPushButton
from pyside_iconify import IconWidget, get_icon

app = QApplication([])

# Отдельный виджет значка
icon = IconWidget("mdi:home", size=24, color="red")

# Или передать стандартный QIcon любому виджету
button = QPushButton("Settings")
button.setIcon(get_icon("mdi:cog", size=20))

app.exec()
```

Это весь API для типового случая. Значки скачиваются при первом использовании,
кэшируются на диск и дальше рендерятся локально.

## Возможности

- **Учёт темы** — без заданного цвета значки следуют цвету текста виджета и
  автоматически переключаются между светлой и тёмной темами; отключённые
  значки затухают, а не сереют (многоцветные значки тоже затухают корректно)
- **Полный контроль цвета** — один цвет, маппинг `{оригинал: замена}` для
  многоцветных значков и переопределения по темам (`color_light_theme` /
  `color_dark_theme`)
- **Интуитивные размеры** — числа, `(ширина, высота)`, `QSize`, `"24px"`,
  `"1.5em"` (следует шрифту виджета)
- **HiDPI нативно** — размер в логических пикселях; физические пиксели
  рендерятся по коэффициенту масштаба экрана, наборы @2x/@3x не нужны
- **Загрузка и отсутствие различаются** — при загрузке пусто; подтверждённое
  отсутствие показывает встроенную заглушку и эмитит `failed`; опциональный
  `fallback` — замещающий значок
- **Дружелюбно к QSS** — `qss="toolbar primary"` для группировки, стили —
  нативным `setStyleSheet()`; приоритет: параметры → QSS → тема
- **Типизация и логирование** — полные аннотации типов с `py.typed`,
  стандартный `logging` (по умолчанию молчит)

## Параметры

Общие для `IconWidget` и `get_icon`:

```python
get_icon(name, *, size=24, color=None, color_light_theme=None,
         color_dark_theme=None, selected_color=None, opacity=1.0,
         width=None, height=None, rotate=0, spin=False,
         h_flip=False, v_flip=False)

IconWidget(name, *, ..., hover_color=None, qss=None, parent=None)
```

| Параметр                                 | Значение                                                                    |
| ---------------------------------------- | --------------------------------------------------------------------------- |
| `name`                                   | Имя вида `"mdi:home"` или встроенные данные значка                          |
| `size`                                   | Число, `(ширина, высота)`, `QSize`, `"24px"`, `"1.5em"`                     |
| `color`                                  | Цвет или маппинг `{оригинал: замена}`                                       |
| `color_light_theme` / `color_dark_theme` | Переопределение по темам, главнее `color`                                   |
| `selected_color`                         | Цвет при выборе элемента (item views)                                       |
| `hover_color`                            | Цвет наведения IconWidget / `set_icon` — только явное включение             |
| `opacity`                                | Общая прозрачность 0–1; умножается на альфу цвета                           |
| `width` / `height`                       | Неквадратные значки; главнее `size`                                         |
| `rotate`                                 | Любой угол в градусах, автоуменьшение против обрезки                        |
| `spin`                                   | Непрерывное вращение для индикаторов загрузки                               |
| `h_flip` / `v_flip`                      | Горизонтальное / вертикальное отражение                                     |
| `qss`                                    | Теги группировки QSS, селектор `IconWidget[qss~="tag"]` (только IconWidget) |

Цвета принимают имена CSS/SVG, HEX 3/4/6/8 знаков (порядок `#RRGGBBAA`),
`rgb()/rgba()/hsl()/hsla()`, кортежи, `QColor`, `Qt.GlobalColor`.
Неразбираемый цвет вызывает исключение, а не молча становится чёрным.

## Офлайн-упаковка

Для машин без сети или сборок без внешних зависимостей упакуйте значки перед
релизом:

```powershell
python -m pyside_iconify.pack -o icons.json
```

```python
from pyside_iconify import load_bundle

load_bundle("icons.json")  # при старте приложения; работает и внутри PyInstaller
```

Полный CLI и API — в `src/pyside_iconify/pack.py` и
`tests/test_pack_integration.py`. Локальные данные всегда важнее сети.

## Производительность

Трёхуровневый кэш (данные значка → текст SVG → растровые карты) с бюджетом
памяти; работа за кадр сводится к поиску в кэше и одному `drawPixmap`.
`QListWidget` на 1000 строк строится за ~270 мс и скроллится с нативной
скоростью. Для больших сеток используйте item views с `get_icon`;
`IconWidget` предназначен для отдельных мест со значками.
